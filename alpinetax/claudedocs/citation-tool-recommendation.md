# ATM-38: Citation Tool Recommendation — BrightLocal vs Whitespark

## Recommendation: BrightLocal Citation Builder (pay-as-you-go)

For a single-location practice just getting started, BrightLocal's pay-as-you-go Citation Builder is the clear winner.

## Comparison

| Factor | BrightLocal | Whitespark |
|--------|-------------|------------|
| **Model** | Pay-as-you-go ($3.20/site, $2 with bulk credits) | One-time packages ($399 Premium, $599 Comprehensive) |
| **Subscription** | Optional — Citation Builder works standalone | $1/mo/location for ongoing sync |
| **Sites covered** | 300+ citation sites, submit individually | 35–70 sites depending on package |
| **Data aggregators** | $25 each or $100 for bundle of 5 | Included in packages |
| **Rank tracking** | Included in subscription plans ($39+/mo) | Separate tool ($14–$200/mo) |
| **Flexibility** | Pick exactly which sites, pay per submission | Package-based, less granular |
| **Best for** | Budget-conscious, single location, DIY | Agencies, hands-off, multi-location |

## Why BrightLocal for Alpine Tax

1. **Cost control**: At $3.20/submission, building 75 citations costs ~$240 total vs $399–$599 for Whitespark's packages
2. **No subscription required**: Citation Builder is standalone — no monthly fee for a single location
3. **Granular control**: Submit to specific directories that matter for CPAs/tax professionals (Yelp, BBB, YP, Avvo, etc.)
4. **Data aggregators**: Can add the 4 major aggregators (Factual/Foursquare, Neustar, Data.com, Infogroup) for $100 bundled
5. **Growth path**: If we later want rank tracking or GBP audit tools, can add a subscription ($39/mo Track plan)

## Execution Plan

### Phase 1: Data Aggregators (Week 1)
- Submit to 4 major data aggregators via BrightLocal ($100 bundle)

- Cost: ~$50–80
