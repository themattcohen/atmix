The fingerprint

Each lot code pairs a cap colour with a collar colour and a three-digit batch number — for example GLD-BLK-014 marks a gold cap, black collar, batch fourteen. The combination is unique to a single tested run and is printed nowhere else. It exists only to resolve to one record: the identity, purity, and testing method filed for that batch, and nothing beyond it.
