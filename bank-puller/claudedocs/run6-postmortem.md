## Architecture Observations

### What's Working Well
1. **Bug 4 fix (TOTP graceful failure)**: Mercury's TOTP failure was handled cleanly — the session logged an error and moved on to the next bank instead of crashing. This is exactly the right behavior.
2. **Playbook system**: Citibank login via playbook hit 100% (8/8 hits). The playbook replay for username, password, and submit worked perfectly — the failure was post-login.
3. **Cost efficiency**: 54 AI calls at $0.27 is very reasonable. The half-resolution screenshot optimization is working.
4. **Multi-window parallelism**: W1 and W2 ran concurrently, processing different banks in parallel. The action log shows proper interleaving.
5. **Stuck-counter with Escape+reload**: The BofA loop correctly triggered the stuck counter and tried recovery. It just didn't help because the page state was genuinely unrecoverable (enrollment page).

### Recurring Patterns
1. **"Page state not in vocabulary" loop**: Both BofA (`enrollment → unknown`) and Citi (`sign-on method → 2fa_method_selection`) hit states the AI vocabulary doesn't cover. Every unrecognized state costs 7s of AI time per iteration. **Fix**: expand the page state vocabulary and add an "unrecoverable" category.
2. **verified_click burning time on SPAs**: 5+ banks hit verified_click failures, each costing ~8s (click + 4 offset retries). On SPAs, the click works but the screenshot doesn't change visually. **Fix**: add URL-change detection.
3. **Blank screenshots / unloaded pages**: Both Chase (loading spinner at `0004_w1_ready_0.png`) and Dialpad (blank white) hit rendering issues. **Fix**: add pre-AI screenshot validation — if screenshot is >95% single color, don't waste an AI call on it.

### Suggestions for Making the Agent Smarter

1. **Pre-AI screenshot validation**: Before sending any screenshot to Claude, check if it's blank or shows a loading spinner. Save AI calls and time.

2. **Page state vocabulary expansion**: Add `enrollment`, `sign_on_method`, `captcha`, `maintenance`, `timeout_expired` to the classifier's vocabulary. Each saves an entire stuck loop.

3. **Two-step navigation for statements**: Some banks (Amex, possibly others) hide statements behind menus. Implement a fallback in `_phase_statements_nav`: if direct link not found, try clicking hamburger/menu buttons first.

4. **Early abort on unrecoverable states**: If the AI classifies `unknown` with >0.90 confidence twice in a row, the page is genuinely unrecognized — don't loop 10 times. Abort after 3 consecutive `unknown` at high confidence.

5. **Dialpad health gate**: If Dialpad screenshots are blank, skip all SMS-dependent banks immediately and log them as "Dialpad unavailable" rather than timing out on each one.
