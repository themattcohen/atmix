# Blog Engine

SEO article pipeline. Generates, optimizes, and deploys blog content.

## Stack

Node.js + Python hybrid. Deployed on Hetzner via SCP.

- `claudedocs/deployment-runbook.md` -- deploy steps and troubleshooting
